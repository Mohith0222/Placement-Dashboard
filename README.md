# 🚀 Placement Metrics Dashboard

A **modern, interactive placement management and analytics system** built using HTML, CSS, and JavaScript.
This project simulates a real-world admin dashboard used to track, analyze, and evaluate student placement performance.

## 📌 Project Overview

The Placement Metrics Dashboard is designed to:

* Manage student placement data efficiently
* Provide real-time analytics and insights
* Visualize placement trends using charts
* Generate reports for decision-making

It combines **data management + analytics + reporting** in a single interface.

---

## ✨ Key Features

### 🔐 Authentication

* Admin login system (session-based using localStorage)
* Protected dashboard access
* Logout functionality

### 📊 Dashboard Analytics

* Total students count
* Placed students count
* Average CGPA calculation
* Real-time updates

### 🧾 Student Management (CRUD)

* Add, edit, delete student records
* Unique roll number validation
* Data persistence using localStorage

### 🔎 Search, Filter & Sort

* Search by name, roll number, and skills
* Filter by placement status and CGPA range
* Sort by CGPA and name

### 📈 Data Visualization

* Pie chart: Placement status (Placed vs Not Placed)
* Bar chart: CGPA distribution
* Dynamic updates using Chart.js

### 📤 Export & Reporting

* Export data to CSV (Excel-compatible)
* Generate PDF reports using jsPDF

### 📥 Sample Data

* One-click dataset loading for demo/testing

### ✅ Validation

* Form validation with inline error messages
* CGPA constraints and unique roll numbers

---

## 🧠 Advanced Features (Unique Additions)

* 📊 Placement Readiness Score (rule-based evaluation)
* ⚠️ Risk identification (low-performing students)
